# HACKATHON_SEMANA_DE_LA_CIENCIA_404s_TO_MARS

Proyecto web desarrollado para el concurso Hackathon de la Semana de la Ciencia. Consiste en diseñar y desarrollar una página de error 404 creativa y responsive, simulando un fallo en la misión a Marte.

## Características principales

- Página 404 personalizada con temática espacial.
- Diseño responsive para diferentes dispositivos.
- Animaciones y efectos visuales.
- Compatible con navegadores modernos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
